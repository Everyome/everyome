**What it shows.** The protein as a line from its first to its last residue. Each row is one member database's matches;
the top row shows the InterPro entries they belong to. Matches of the same colour belong to the same entry.

- The order of domains along a protein (its architecture) often says more than any one domain: a kinase domain next to
  an SH3 domain is a different kind of kinase from one standing alone.
- Repeats (leucine-rich repeats, zinc fingers) show as several short matches in a row.
