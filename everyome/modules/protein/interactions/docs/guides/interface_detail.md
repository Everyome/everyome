**What it shows.** The residues on each side of the interface (letters and numbers along each chain), and the
predicted aligned error between the two chains: each square is how far one chain's residue may be misplaced when the
other chain is held fixed.

- A dark patch where the interface residues meet, and pale elsewhere, is typical of a confident interface.
- Pale everywhere: the predictor doesn't know how the chains sit relative to each other, even if each chain is folded.
