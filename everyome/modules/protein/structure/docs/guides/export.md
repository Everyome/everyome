**What you get.** The top-ranked model of each prediction you choose, as a PDB file with pLDDT in the B-factor
column (so viewers can colour by confidence), and a summary table.

- **Trim below a pLDDT** to remove low-confidence parts, for example to make a search model for molecular
  replacement (70 is a common choice) or a cleaner figure.
- **Only confident domains** keeps the domains listed in *Look at a structure*.
- The files from the pipeline itself stay untouched in `results/`.
