**What it shows.** Every tested peak: its log2 fold change (right = more open in the test group) against how sure the
test is (up = smaller adjusted P). Coloured peaks pass both thresholds.

- Peaks far right or left and high up are large, consistent changes. Small changes can be significant in strong peaks
  with many reads; set a minimum fold change to focus on larger ones.
- Search a gene name in the table to find the peaks near it.
