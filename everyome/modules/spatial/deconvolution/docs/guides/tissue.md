**What it shows.** One cell type's estimated cells (or share) in every spot.

- A cell type should sit where you expect it in the tissue: keratinocytes in the epidermis, smooth muscle in muscle.
- The **cautious estimate** (5% quantile) is lower: where it is still clearly above zero, you can be confident the type
  is there.
- Spots at a boundary between regions usually hold several types, so each type fades out rather than stopping sharply.
