**What it shows.** How many cells of each type were found, overall, in each section, and in how many spots each type is
the main one.

- Totals should follow what you know of the tissue: a type you expect to be common should not be rare.
- A type found everywhere at low levels may be standing in for a cell type missing from the reference.
- **Cells per spot** should be near the number you expected. Far more or fewer suggests the setting, or the reference,
  doesn't fit this tissue.
