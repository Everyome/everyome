**Rooting.** The tree IQ-TREE builds has no root: it says which sequences are closest, not which came first.
A root turns it into a history.

- **Outgroup**: sequences you know sit outside the group you study (for example a related family or phylum).
  The root goes on the branch between them and everything else. The outgroup must form one group on the tree.
- **Midpoint**: halfway along the longest path between two sequences. Reasonable when there is no outgroup,
  but it assumes roughly equal rates of change and can be wrong when one lineage evolves fast.
- **Collapsing** a group draws it as a triangle (its length shows the longest branch inside), to make large
  trees readable. It changes nothing in the tree itself.
- Dots mark well-supported branches (SH-aLRT ≥ 80% and UFBoot ≥ 95%); choose *numbers* to see the values.
