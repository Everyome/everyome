**What it shows.** For the column you colour by, whether all the sequences with each value form **one group**
(a clade: one branch with everything below it, and nothing else) on the tree as it is rooted now.

- *yes* with high support: the data back that group. *no*: the sequences with that value are split across the
  tree. That can be real (a trait gained or lost more than once) or a sign of a mislabelled or misplaced sequence.
- Whether a group is a clade depends on the root. Root on a sensible outgroup before reading this table.
