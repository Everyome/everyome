**What you get.** The tree as drawn here: rooted the way you chose, with support values, plus the figure.

- Collapsing and colouring change only the figure; `tree_rooted.nwk` always has every sequence.
- The figure uses neutral colours so it suits a paper or slide; edit it in any vector drawing program.
- To redraw it in R: `ape::read.tree("tree_rooted.nwk")`; in Python: `Bio.Phylo.read("tree_rooted.nwk", "newick")`.
