**What it shows.** What the three stages produced.

- **Columns kept**: how much of the alignment survived trimming. Keeping well under half is a sign the sequences
  are hard to align (very different, or not all the same gene).
- **Model**: the model of evolution IQ-TREE used. With `MFP`, ModelFinder chose it.
- IQ-TREE's own report (`tree.iqtree`) has every number, including the parameters of the model.
