**What it shows.** Each row is a sequence and each column a position; letters in one column are assumed to
descend from the same ancestral position. Pale columns were removed by trimming.

- Blocks of colour that line up across rows are conserved regions: the strongest evidence for the tree.
- A row that is mostly empty is a **partial sequence**. It can still be placed, but with less certainty.
- A row whose letters rarely match the others may be a **different gene** (a paralogue), a contaminant or a
  poor sequence. Check it before trusting where it sits in the tree.
- **Same as consensus** is the share of a sequence's letters (after trimming) that match the most common
  letter in their column.
