# Everyome logo

The Everyome logo is the **Growth rings** mark: four open rings, each turned a little further, growing outward.
These files are in **House Style 1: Creation**, the default theme; the app draws the same mark in the colours of
whichever theme is active. Logo designed by Helen R Horkan PhD for Everyome.

| File | Use |
|---|---|
| `everyome_wide_light.svg`, `everyome_wide_dark.svg` | Logo with the name, on light or dark backgrounds (the README uses these) |
| `everyome_mark_light.svg`, `everyome_mark_dark.svg` | The mark alone |
| `everyome_stacked-tagline_light.svg`, `…_dark.svg` | Mark over the name, with the tagline |
| `everyome_icon_light_512.png`, `…_dark_512.png` | App icon |
| `everyome_social_preview_1280x640.png` | The repository's social preview (GitHub: Settings, General, Social preview) |

The app's favicon is `everyome/static/favicon.svg` and `favicon.ico`. The full set, in every theme and format (PNG,
PDF, web icons, PowerPoint templates), is kept outside the repository with the scripts that make it.

Keep clear space around the logo of at least a quarter of the mark's width; do not stretch, recolour by hand or set
"everyome" in another font (it is JetBrains Mono: 400 for "every", 800 for "ome").
